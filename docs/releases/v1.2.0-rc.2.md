# WhatsApp Electron v1.2.0-rc.2 — stable update hardening candidate

This is a proposed next prerelease candidate for the unofficial Linux wrapper.
It does not replace or modify the existing public `v1.2.0-rc.1` release. This
file is prepared for review; no tag or release is created by this change.

## Changes

- Update the pinned Electron runtime to 43.8.6 and electron-builder to 26.18.1.
- Add **Help → Check for Updates** for exact Personal release assets. The app
  opens the project's GitHub release page without downloading or running a
  package.
- Add optional daily checks, disabled by default and stored in the existing
  profile preferences. Business release checks remain disabled pending written
  distribution authorization.
- Document the remaining moderate development dependency advisory and Linux
  package-manager/AppImage upgrade steps.

## Not certified by this candidate

Account linking, existing-session restore, messaging, attachments, notifications,
tray behavior on the desktop matrix, and voice/video calls still need manual
acceptance. Screen sharing remains blocked. The remaining npm audit findings
are listed in [the dependency review](../security-audit-stable-update.md).

Public Business binary distribution remains blocked pending written
authorization. Review the [release gates](../release-readiness.md) before any
publication. No installer is run automatically; verify package checksums before
installing DEB/RPM packages or replacing an AppImage.
